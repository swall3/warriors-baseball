# InningWise mobile pilot

The Android pilot is a Trusted Web Activity for `https://inningwise.com/` with application ID `com.inningwise.app`. The source is in `android/`. It was generated by PWABuilder for the existing PWA and targets Android API 36. The signed pilot APK and AAB are stored outside Git. The signing keystore and its credentials are backed up privately; never commit or share them. Future versions must use the same signing key for in-place updates.

`public/.well-known/assetlinks.json` associates the site with this pilot signing certificate. Deploy that file before sharing the APK; otherwise Android opens the site with a browser address bar. If a future Google Play build uses Play App Signing, add its Play certificate fingerprint to the same file. Keep the pilot fingerprint for existing sideloaded installs.

The app needs an internet connection. It loads the production website, so pilot testers will use production accounts and data. Test sign-in, parent join, coach access, game scoring, and billing on physical devices before expanding the pilot. Do not use real payments for a test purchase.

The iOS prototype was generated separately, but it is not a distributable build. It needs native cleanup, an Apple Developer Program membership for signing and TestFlight, and a hosted macOS build. Public App Store distribution will also require a review of the native experience and the existing web subscription purchase flow against Apple's rules.
